# OpenAPI validation schemas

These files are informational JSON Schemas published by the OpenAPI
Initiative. OpenAPI.jl uses them for the structural validation pass. The
normative OpenAPI Specification remains authoritative when it differs from a
schema.

- `oas-3.0.json`: <https://spec.openapis.org/oas/3.0/schema/2024-10-18>
- `oas-3.1.json`: <https://spec.openapis.org/oas/3.1/schema/2025-09-15>
- `oas-3.2.json`: <https://spec.openapis.org/oas/3.2/schema/2025-11-23>
